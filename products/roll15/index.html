1. Local processing

ROLL15 records or imports videos as Rolls and combines them into a final Tape. Videos, microphone audio, editing and export are processed on your Android device. ROLL15 does not send your videos or project data to the developer or a server. The app has no user accounts, advertising, crash-reporting or in-app billing SDK.

2. Permissions and selected media

Camera permission enables recording. Microphone permission is requested for camera recording with SOUND ON; SOUND OFF produces a silent Roll. Imported SOUND ON preserves source audio. The system picker provides access only to videos you select. Foreground-service permissions support user-started Tape processing; a system notification indicates ongoing processing. Vibration provides button feedback.

3. Storage and retention

Rolls and project metadata are stored in app-private storage. Metadata includes local paths, selected source URI and segment, duration, order, camcorder, SOUND setting, framing and processing status, and source media dimensions, rotation, format, audio and capture time when available. Individual Rolls can be deleted; recovery or conflict references may retain files while they remain referenced. Inactive draft Tapes can be deleted from the Tape Library. Users can explicitly export a draft backup to a destination selected in the Android file picker, and restore it later. These backups contain project metadata and finished Roll media; source imports, interrupted operations and recovery history are not included. Library cover selections are stored locally. Clearing app data or uninstalling removes app-private data. Android automatic backup is disabled and app-private data is excluded from device transfer.

4. Final Tapes and sharing

Final Tapes are saved to Android MediaStore in Movies/ROLL15 and remain after uninstalling the app. You can delete them in the Tape library, gallery or file manager. Gallery or system backup services may back up these shared files according to your own settings; ZEROSEOK does not operate those backups. When you choose SHARE or OPEN, the receiving app is granted access to the selected Tape and handles it under its own privacy policy.

5. Security and choices

ROLL15 uses Android app-private storage and does not add separate file encryption. No remote account or server profile is created. You can revoke camera or microphone permissions in Android settings, select which videos to import, and remove stored data as described above. Contact zerostonz.co@gmail.com with privacy questions. Any changes to this policy will be published here with an updated date.

한국어

1. 기기 내 처리

ROLL15는 동영상을 촬영하거나 가져와 Roll을 만들고, 이를 최종 Tape로 저장하는 Android 앱입니다. 영상, 마이크 오디오, 편집 및 내보내기는 기기 안에서 처리됩니다. 앱은 영상이나 프로젝트 데이터를 개발자 또는 서버로 전송하지 않습니다. 사용자 계정, 광고, 오류 보고, 인앱 결제 SDK가 없습니다.

2. 권한과 선택한 영상

카메라 권한은 촬영에 사용합니다. 카메라의 SOUND ON 촬영에만 마이크 권한을 요청하며, SOUND OFF는 무음 Roll을 만듭니다. 가져온 영상의 SOUND ON은 원본 오디오를 유지합니다. 시스템 선택기로 사용자가 고른 영상에만 접근합니다. 포그라운드 서비스 권한은 사용자가 시작한 Tape 처리를 지원하며, 처리 중 시스템 알림을 표시합니다. 진동은 버튼 피드백에 사용합니다.

3. 저장 및 보관

Roll과 프로젝트 정보는 앱 전용 저장소에 보관합니다. 저장 정보에는 로컬 경로, 선택한 원본 URI 및 구간, 길이, 순서, 캠코더, SOUND 설정, 화면 구성, 처리 상태와 확인 가능한 원본 영상의 크기·회전·형식·오디오·촬영 시각이 포함됩니다. 개별 Roll은 삭제할 수 있으나 복구 또는 충돌 참조가 남아 있으면 해당 파일이 보관될 수 있습니다. 테이프 라이브러리에서 비활성 초안 테이프를 삭제할 수 있습니다. Android 파일 선택기로 초안 백업을 내보내고 복원할 수 있습니다. Android에서 앱 데이터 삭제 또는 앱 제거 시 앱 전용 데이터가 삭제됩니다. 자동 백업은 비활성화되어 있으며 앱 전용 데이터는 기기 전송에서 제외됩니다.

4. 최종 Tape 및 공유

최종 Tape는 Android MediaStore의 Movies/ROLL15에 저장되며 앱을 제거해도 남습니다. Tape 라이브러리, 사진첩 또는 파일 앱에서 삭제할 수 있습니다. 사진첩이나 시스템 백업 서비스는 사용자 설정에 따라 공유 파일을 백업할 수 있으며, ZEROSEOK는 해당 백업을 운영하지 않습니다. SHARE 또는 OPEN을 선택하면 선택한 Tape에 대한 접근 권한을 받는 앱에 제공합니다. 이후 처리는 해당 앱의 개인정보처리방침을 따릅니다.

5. 보안 및 선택권

앱은 Android 앱 전용 저장소를 사용하며 별도의 파일 암호화를 추가하지 않습니다. 원격 계정이나 서버 프로필을 만들지 않습니다. Android 설정에서 카메라·마이크 권한을 해제하고 가져올 영상을 선택하며 위 방법으로 저장 데이터를 삭제할 수 있습니다. 개인정보 관련 문의는 zerostonz.co@gmail.com으로 보내주세요. 정책 변경 시 이 페이지와 수정 날짜를 갱신합니다.

Optional usage analytics

Usage analytics is optional and off by default. Where offered in the app, you can enable or disable it from the in-app privacy page. If enabled, Google Analytics for Firebase receives app interactions and task outcomes, app and device information, an app-instance identifier, and approximate location derived from IP to help improve the app. Analytics events exclude user content, file names and paths, precise location, and raw error messages. Advertising ID collection and ad personalization are disabled.

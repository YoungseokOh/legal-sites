ENGLISH

What KoreanCheck does

KoreanCheck is an Android Korean writing checker provided by ZEROSEOK. Quick Check runs locally using the KorLint Rust engine and its Korean dictionary. It does not send the text you check to a server.

AI Review and text you choose

AI Review runs only after you tap it. The Korean text you choose, your requested explanation language, the app version, and compact findings from Quick Check are sent to a KoreanCheck backend hosted on Firebase. The backend sends the selected text to OpenAI to produce corrections and optional natural-language suggestions. Do not submit information you do not want processed by these services.

The OpenAI request uses store:false, which prevents Responses application-state storage, but does not turn off OpenAI abuse-monitoring logs. Under OpenAI's default API settings, those logs may retain request and response content for up to 30 days unless an approved project-specific retention control applies. OpenAI says API content is not used to train its models by default. OpenAI and Google otherwise process service data under their own terms and privacy documentation. AI output may be wrong; review suggestions before applying them.

Authentication, quota, and diagnostics

AI Review uses Firebase anonymous authentication and App Check for request security and abuse prevention. The service stores a SHA-256-derived anonymous identifier with a daily request count to enforce limits, plus an aggregate daily count. These records do not contain the Korean text or AI response. Server logs may contain the model, request outcome, latency, token counts, and counts of returned corrections; source text and correction content are not logged.

The anonymous identifier is stored by Firebase Authentication on your device and is not a profile with a name, email address, or sign-in screen. Clearing KoreanCheck's app data or uninstalling the app removes the local identifier. The pseudonymous quota record on the server may remain for abuse prevention and is overwritten when that identifier is used on a later day.

Storage, analytics, and sharing

KoreanCheck does not save the text you type as an account document. The Android app does not include ads or a user-behavior analytics SDK. Limited AI service metrics such as request status, response time, token counts, and result counts may be logged as described above. We do not sell personal information. Google Firebase and OpenAI receive only the information needed for an AI Review request and service operation as described above.

Children, security, and changes

KoreanCheck is a general writing utility and is not directed to children under 13. Online requests use encrypted network connections and server-side access controls. No method of electronic processing can guarantee absolute security. We will update this page if our data practices change materially.

한국어

서비스와 로컬 점검

KoreanCheck는 ZEROSEOK이 제공하는 Android 한국어 글쓰기 점검 앱입니다. 빠른 점검(Quick Check)은 KorLint Rust 엔진과 한국어 사전을 기기 안에서 실행하며, 점검한 글을 서버로 전송하지 않습니다.

AI 검토와 사용자가 선택한 글

AI 검토(AI Review)는 사용자가 직접 버튼을 눌렀을 때만 실행됩니다. 사용자가 선택한 한국어 글, 설명 언어, 앱 버전, 빠른 점검의 간략한 결과가 Firebase의 KoreanCheck 백엔드로 전송됩니다. 백엔드는 선택된 글을 OpenAI에 전달해 교정과 선택적 자연스러운 표현 제안을 만듭니다. 해당 서비스에서 처리되기를 원하지 않는 정보는 제출하지 마세요.

OpenAI 요청에는 store:false를 사용해 Responses 애플리케이션 상태 저장을 막지만, 이 설정이 OpenAI의 오남용 모니터링 로그까지 끄지는 않습니다. OpenAI의 기본 API 설정에서는 승인된 프로젝트별 보관 제어가 적용되지 않는 한 요청·응답 내용이 오남용 모니터링 로그에 최대 30일까지 보관될 수 있습니다. OpenAI는 기본적으로 API 콘텐츠를 모델 학습에 사용하지 않는다고 안내합니다. 그 밖에 OpenAI와 Google은 각자의 약관과 개인정보 문서에 따라 서비스 데이터를 처리합니다. AI 결과는 틀릴 수 있으니 적용 전에 확인해 주세요.

인증, 사용량 제한, 진단 정보

AI 검토 요청의 보안과 오남용 방지를 위해 Firebase 익명 인증과 App Check를 사용합니다. 사용량 제한을 위해 SHA-256으로 변환된 익명 식별자와 일일 요청 횟수, 전체 일일 요청 횟수를 저장합니다. 이 기록에는 한국어 원문이나 AI 응답이 포함되지 않습니다. 서버 로그에는 모델, 요청 결과, 처리 시간, 토큰 수, 반환된 교정·제안 개수 등이 포함될 수 있지만 원문과 교정 문장은 기록하지 않습니다.

익명 식별자는 Firebase Authentication에 기기 내 저장되며 이름, 이메일 주소 또는 로그인 화면을 갖는 사용자 프로필이 아닙니다. 앱 데이터 삭제 또는 앱 제거 시 기기의 식별자가 삭제됩니다. 서버의 가명 처리된 사용량 기록은 오남용 방지를 위해 남을 수 있으며, 같은 식별자로 다음 날 검토를 이용하면 최신 일일 횟수로 덮어씁니다.

저장, 분석, 제3자 제공

KoreanCheck는 사용자가 입력한 글을 계정 문서로 저장하지 않습니다. Android 앱에는 광고나 사용자 행동 분석 SDK가 없습니다. AI 서비스 운영을 위해 요청 상태, 응답 시간, 토큰 수, 결과 개수와 같은 제한적인 지표가 앞에서 설명한 대로 기록될 수 있습니다. 개인정보를 판매하지 않습니다. Google Firebase와 OpenAI에는 AI 검토 요청과 서비스 운영에 필요한 정보만 전달됩니다.

아동, 보안, 변경

KoreanCheck는 일반 글쓰기 도구이며 만 13세 미만 아동을 대상으로 하지 않습니다. 온라인 요청은 암호화된 연결과 서버 접근 제어를 사용합니다. 전자적 처리의 안전성을 절대적으로 보장할 수는 없습니다. 데이터 처리 방식에 중요한 변경이 있으면 이 페이지를 업데이트합니다.

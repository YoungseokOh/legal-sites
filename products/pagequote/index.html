English

Quotes, images and on-device OCR

PageQuote stores book titles, quotes, optional page numbers, tags, study notes, creation times and review schedules locally. It can read an image you choose or use its camera screen after camera permission is granted. Camera access is optional: manual entry and image selection remain available without it. Latin and Korean text recognition uses bundled models on your device, not a server.

Image retention and record deletion

Selected images are decoded into memory for preview and recognition; PageQuote does not modify or delete the gallery original and does not save source images with your quotes. Camera JPEGs are private temporary files. The reader deletes its own camera file after the actual read finishes, including abandoned reads; if a provider stalls, cleanup may wait for the worker to finish. Next-process startup removes orphan captures. Rotation can retain the live preview; process recreation drops the image and requires selection again. You can remove an image while keeping typed text. Delete quotes in the library; registered empty books may remain until app storage is cleared or the app is uninstalled.

Study-card export

CSV export contains the quote, the study note and book/page context, and tags. It does not contain the source image or PageQuote review schedule. You choose the destination. CSV is not a full PageQuote backup and the app does not provide a backup-import/restore feature.

PageQuote local diagnostics and optional reports

PageQuote’s own diagnostic feature keeps bounded diagnostic events, coded outcomes, timestamps, app version and a random local installation identifier in app-private storage. These records are not automatically transmitted and do not include your saved content or precise coordinates. Help & feedback lets you export a diagnostic file to a location you choose; it does not send a report to ZEROSEOK. You can clear the local activity log in the app.

Google ML Kit metrics

PageQuote includes Google ML Kit’s bundled text-recognition SDK. Google states that input images/text and recognized results are processed on-device, while ML Kit collects device/app information, installation identifiers, performance and API-usage metrics for diagnostics and analytics. Google describes HTTPS protection for these metrics. ML Kit’s terms describe sending SDK metrics to Google for API diagnostics and improvement. This SDK processing is separate from PageQuote’s optional local report export. See ML Kit’s data disclosure, ML Kit Terms & Privacy and Google’s Privacy Policy.

Network, providers and this website

PageQuote has no account, developer upload server or advertising. Its Android manifest does not request Internet permission; that setting does not replace the ML Kit disclosures above. Choosing a document provider may cause that provider to download or upload a file under its own policy. Exported files remain at the destination you choose, and a provider or receiving app may process them under its own policy. Opening this privacy page uses your browser. This page is hosted on GitHub Pages; GitHub handles website request information under its own privacy policy. If you email us, we receive the address, message and attachments you choose to send, and use them to respond to your inquiry; your email provider also processes the message.

Storage, backup and deletion

Local data is kept within Android app-private storage; the Android sandbox restricts other apps’ access. The app does not add its own file encryption. Android cloud backup and device-transfer backup are disabled for app data. Clearing Android app storage or uninstalling removes the private data. Exported files and any files retained by another provider must be deleted separately from their chosen destination.

Contact and changes

ZEROSEOK operates this app. For privacy questions, contact seok7302@gmail.com. Changes to this policy will be reflected on this page with an updated effective date.

한국어

문장·이미지·기기 내 문자 인식

PageQuote는 책 제목, 문장, 선택적 페이지, 태그, 학습 노트, 생성 시각과 복습 일정을 기기에 저장합니다. 사용자가 선택한 이미지를 읽거나 카메라 권한을 허용한 뒤 앱의 촬영 화면을 사용할 수 있습니다. 카메라는 선택 사항이며 권한이 없어도 직접 입력과 이미지 선택을 사용할 수 있습니다. 라틴 문자와 한글 인식은 서버가 아닌 기기에 포함된 모델로 처리합니다.

이미지 보관과 기록 삭제

선택한 이미지는 미리보기와 인식을 위해 메모리로 읽습니다. 갤러리 원본을 수정·삭제하지 않고 원본 이미지를 문장과 함께 저장하지 않습니다. 촬영 JPEG는 앱 전용 임시 파일입니다. 읽기 작업이 취소되었더라도 실제 읽기가 끝나면 해당 작업이 자신의 촬영 파일을 삭제합니다. 제공자가 지연되면 작업 종료까지 정리가 늦어질 수 있습니다. 다음 앱 프로세스 시작 시 남은 임시 촬영 파일을 정리합니다. 회전 중에는 미리보기가 유지될 수 있지만 프로세스 재생성 시 이미지를 다시 선택해야 합니다. 이미지를 제거해도 입력한 문장은 유지할 수 있습니다. 보관함에서 문장을 삭제할 수 있으며, 등록한 빈 책은 앱 저장 공간을 지우거나 앱을 삭제할 때까지 남을 수 있습니다.

학습 카드 내보내기

CSV에는 문장, 학습 노트와 책·페이지 정보, 태그가 포함됩니다. 원본 이미지나 PageQuote 복습 일정은 포함하지 않습니다. 사용자가 저장 위치를 선택합니다. CSV는 PageQuote 전체 백업이 아니며 앱에 백업 가져오기·복원 기능은 없습니다.

PageQuote 로컬 진단과 선택적 보고서

PageQuote 자체 진단 기능은 앱 내부 저장소에 개수가 제한된 진단 이벤트, 결과 코드, 시각, 앱 버전과 무작위 로컬 설치 식별자를 보관합니다. 진단 기록은 자동 전송하지 않으며 저장한 콘텐츠나 정밀 좌표를 포함하지 않습니다. Help & feedback에서 사용자가 선택한 위치에 진단 파일을 내보낼 수 있지만 ZEROSEOK로 보내지는 않습니다. 앱에서 로컬 활동 기록을 지울 수 있습니다.

Google ML Kit 지표

PageQuote에는 Google ML Kit의 번들 문자 인식 SDK가 포함됩니다. Google은 입력 이미지·문자와 인식 결과를 기기에서 처리하며, ML Kit가 진단·분석을 위해 기기·앱 정보, 설치 식별자, 성능·API 이용 지표를 수집한다고 고지합니다. Google은 지표 전송에 HTTPS를 사용한다고 설명합니다. ML Kit 약관은 API 진단·개선을 위해 SDK 지표를 Google에 전송한다고 설명합니다. 이 SDK 처리는 PageQuote의 선택적 로컬 보고서 내보내기와 별개입니다. ML Kit 데이터 고지, ML Kit 약관·개인정보 안내, Google 개인정보처리방침을 참고하세요.

네트워크·제공자·이 웹사이트

PageQuote에는 계정, 개발자 업로드 서버나 광고가 없습니다. Android 매니페스트에 인터넷 권한이 없지만 이 설정이 위 ML Kit 고지를 대체하지는 않습니다. 문서 제공자를 선택하면 해당 제공자가 자체 방침에 따라 파일을 내려받거나 업로드할 수 있습니다. 내보낸 파일은 선택한 위치에 남으며 제공자나 수신 앱이 자체 방침에 따라 처리할 수 있습니다. 이 개인정보처리방침은 사용자의 브라우저로 열립니다. 웹페이지는 GitHub Pages에서 제공하며 GitHub는 자체 개인정보처리방침에 따라 웹 요청 정보를 처리합니다. 이메일 문의 시 사용자가 보낸 주소·메시지·첨부파일을 받아 문의에 답변하는 데 사용하며, 이메일 제공자도 메시지를 처리합니다.

저장·백업·삭제

로컬 데이터는 Android 앱 내부 저장소에 보관하며 Android 샌드박스가 다른 앱의 접근을 제한합니다. 앱 자체 파일 암호화는 추가하지 않습니다. 앱 데이터의 Android 클라우드 백업과 기기 이전 백업은 비활성화합니다. Android에서 앱 저장 공간을 지우거나 앱을 삭제하면 비공개 데이터가 제거됩니다. 내보낸 파일이나 다른 제공자가 보관한 파일은 선택한 위치에서 별도로 지워야 합니다.

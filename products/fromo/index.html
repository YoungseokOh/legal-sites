Privacy Policy / 개인정보처리방침

Optional usage analytics

Usage analytics is optional and off by default. Where offered in the app, you can enable or disable it in settings. If enabled, Google Analytics for Firebase receives app interactions and task outcomes, app and device information, an app-instance identifier, and approximate location derived from IP to help improve the app. Analytics events exclude user content, file names and paths, precise location, and raw error messages. Advertising ID collection and ad personalization are disabled.

선택형 사용 분석

사용 분석은 기본적으로 꺼져 있으며, 앱에서 해당 기능을 제공하는 경우 설정에서 켜거나 끌 수 있습니다. 동의하면 앱 개선을 위해 기능 사용 및 작업 결과, 앱과 기기 정보, 앱 인스턴스 식별자 및 IP에서 파생된 대략적인 지역 정보가 Google Analytics for Firebase로 전송됩니다. 분석 이벤트에 사용자 콘텐츠, 파일 이름·경로, 정확한 위치 및 원본 오류 메시지는 포함되지 않습니다. 광고 ID 수집과 광고 개인화는 사용하지 않습니다.
